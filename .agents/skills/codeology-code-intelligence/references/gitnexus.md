# Optional GitNexus workflow

GitNexus can index source symbols and expose dependency, call-chain and change-impact tools. If an approved installation is present:

1. Check index status before trusting results.
2. Use context and trace for unfamiliar flows.
3. Use impact before contract or shared-component changes.
4. Use change detection during review.
5. Verify material claims against source and tests.
6. Re-index after meaningful commits.

Do not use its graph as a curriculum dependency graph. Avoid embeddings and statement-level analysis until basic indexing proves useful.
