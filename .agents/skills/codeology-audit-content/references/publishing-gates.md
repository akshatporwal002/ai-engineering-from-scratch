# Publishing gates

- Every content path resolves to exactly one source rule.
- Imported content retains project, author, URL, licence and upstream commit.
- Adapted content resolves both its original source and Codeology sidecar.
- Original Codeology content is never labelled as upstream.
- IDs are stable and unique; aliases cover approved renames.
- Prerequisites contain no cycles or missing targets.
- Scenario criteria map to declared skills and rubric versions.
- Public pages contain no hidden tests, private prompts or assessor-only thresholds.
- Builders and audits exit successfully before deployment.
