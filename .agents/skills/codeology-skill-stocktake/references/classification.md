# Skill classification

- **Daily:** repeatedly required for ordinary repository work.
- **Specialist:** valuable for a defined domain but should load only on matching tasks.
- **Library:** retained for rare use and explicit invocation.
- **Merge:** materially duplicates another skill and can be consolidated without weakening triggers.
- **Retire:** obsolete, broken, unsafe, or unsupported by current repository evidence.

Score usefulness from actual repository paths, recent work and documented plans. Popularity outside this project is not sufficient evidence.
