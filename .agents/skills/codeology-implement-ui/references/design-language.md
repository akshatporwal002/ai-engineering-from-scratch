# Codeology design language

- **Canvas:** pure white or pure black.
- **Hierarchy:** bold editorial typography, generous negative space and compact labels.
- **Accent:** controlled high-energy orange/pixel treatment; use it for state and emphasis, not every surface.
- **Components:** modern rounded geometry, restrained translucency, soft elevation and clear interactive affordances.
- **Data:** skill trees may glow progressively, but also need labels, icons, patterns or text for accessible state recognition.
- **Motion:** purposeful and reduced-motion safe.
- **Content:** long lessons remain highly readable; assessment evidence must scan quickly.
- **Consistency:** derive new components from shared tokens before adding one-off values.
