# Workstream 2 visual and interaction evidence

Evidence is generated by `npm run test:web:e2e` against two local processes:

- legacy static site: `http://127.0.0.1:4173/index.html`;
- Next.js component showcase: `http://127.0.0.1:4174/components`.

All non-loopback browser requests are blocked. The suite captures full-page pairs at 390x844 and 1440x1000, checks horizontal overflow, exercises the mobile navigation, verifies dialog/dropdown focus containment and restoration, and runs axe against the showcase.

## Result

- Playwright: 4/4 tests passed in Chromium.
- Accessibility: zero serious or critical axe violations on `/components`.
- Keyboard: dialog focus wraps, Escape closes, and trigger focus restores; dropdown arrow, Home/End, Escape, and trigger restoration pass.
- Responsive: both legacy and Next pages report no horizontal overflow at 390x844 or 1440x1000; the mobile navigation exposes five 44px-or-taller targets.
- Network boundary: all non-loopback requests were blocked.

## Difference classification

| Material difference | Classification | Reason |
| --- | --- | --- |
| Showcase content differs from the Academy homepage | Intentional | `/components` is a development-only inventory, not a migrated public route. |
| New shell uses the Codeology wordmark and a fixture avatar instead of legacy login controls | Intentional | The runbook requires a presentational, non-authenticating account menu. |
| New mobile shell consolidates legacy page-specific breakpoints at 900px | Intentional improvement | Content order and target sizing remain equivalent while the navigation behavior is consistent. |
| Headline scale, orange hierarchy, serif reading text, monospaced UI labels, hairline rules, pale surfaces, and restrained radii | Parity | Visual inspection of both screenshot pairs shows continuity with the pixel-editorial identity. |
| Explicit light/dark control fixtures and reduced-transparency fallback | Intentional improvement | The states are deterministic and testable without external font or preference services. |
| Missing content, clipped focus, horizontal overflow, or unexplained mobile deterioration | No regression observed | Automated checks and manual screenshot inspection found none. |

One critical axe finding was discovered during development on the invalid Evidence URL fixture. The browser DOM lacked a usable accessible name; the fixture now has an explicit redundant `aria-label`, and the repeated axe run passes.
